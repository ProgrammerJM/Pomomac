## Pomomac

This is a simple pomodoro timer app developed with the use of NextJS for frontend and Nodejs Express for Backend.
Backend can be seen here: [https://github.com/ProgrammerJM/Pomomac-API]

## Installation

First clone this repository (git clone [https://github.com/ProgrammerJM/Pomomac.git]) then,

# To install the necessary packages and dependencies

```
npm install
```

# To run

```
npm run dev
```
