## Pomomac

This is a simple pomodoro timer web app developed with the use of NextJS as frontend development framework.
Backend side can be seen here: [https://github.com/ProgrammerJM/Pomomac-API]

## Installation

First clone this repository (git clone [https://github.com/ProgrammerJM/Pomomac.git]) then,

# To install the necessary packages and dependencies

```
npm install
```

# To run

```
npm run dev
```
